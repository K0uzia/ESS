# S’engager dans le réseau

Pour que le projet de société porté par l’ESS reste vivant et préserve ses valeurs, l’engagement dans les réseaux qui la composent, est essentiel : dans les fédérations, à l’échelle régionale (CRESS) ou au sein des ADESS de votre territoire (pôles de développement de l’ESS).

Mais par où commencer ? Dans cette section, nous vous présentons plusieurs manières d’aborder votre engagement dans les réseaux.

- [Adhérer aux pôles ESS](https://ess29.org/faire-reseau/pourquoi-et-comment-adherer/)
- [Rencontrer d’autres acteurs de l’ESS](https://ess29.org/agir-dans-less/sengager-dans-le-reseau/rencontres-entre-acteurs-de-less/)
- [Faire de l’économie circulaire](https://ess29.org/agir-dans-less/sengager-dans-le-reseau/achats-responsables-et-economie-circulaire/)
- [Développer les achats responsables](https://ess29.org/agir-dans-less/sengager-dans-le-reseau/achatsresponsables/)
